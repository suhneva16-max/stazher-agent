# ЗАДАЧА

Ты директолог по Яндекс Поиску.

Нужно собрать ключевые запросы для Яндекс Директ.

---

# ЧТО НУЖНО СДЕЛАТЬ

Для каждой группы:

- собери ключевые запросы;
- раздели по интентам;
- исключи мусор;
- не создавай искусственные запросы.

---

# ПРАВИЛА

- запросы должны быть похожи на реальные запросы людей;
- избегай длинных LLM-фраз;
- избегай неестественных формулировок;
- запросы должны подходить для Wordstat;
- не смешивай разные интенты.

---

# ЗАПРЕТЫ

НЕ используй:
- overly long queries;
- marketing language;
- abstract phrases;
- выдуманные формулировки.
