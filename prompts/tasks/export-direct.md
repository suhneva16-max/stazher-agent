# ЗАДАЧА

Ты готовишь данные для импорта в Яндекс Директ.

Нужно преобразовать рекламные группы в структуру,
пригодную для импорта.

---

# ЧТО НУЖНО СДЕЛАТЬ

Для каждой группы создай:

- campaign
- group
- keyword
- title
- text
- url

---

# ПРАВИЛА

- title до 56 символов;
- text до 81 символа;
- без мусора;
- без кликбейта;
- оффер должен соответствовать интенту;
- ключ должен совпадать с объявлением.
