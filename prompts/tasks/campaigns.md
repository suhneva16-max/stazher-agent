# ЗАДАЧА

Ты опытный директолог-стратег.

Твоя задача:
построить структуру рекламных кампаний для Яндекс Директ.

---

# ЧТО НУЖНО СДЕЛАТЬ
# СНАЧАЛА ОПРЕДЕЛИ ТИП СПРОСА

Перед созданием кампаний сначала классифицируй трафик:

- горячий спрос;
- теплый спрос;
- холодный спрос;
- информационный спрос;
- эмоциональный спрос;
- брендовый спрос;
- околоцелевой спрос;
- ретаргетинг.

Для каждого типа спроса:
- определи мотивацию;
- уровень готовности к записи;
- примерные запросы;
- какой тип кампании нужен;
- нужен ли отдельный бюджет.

ТОЛЬКО ПОСЛЕ ЭТОГО строй структуру кампаний.
1. Определи:
- какие кампании нужны;
- какие типы кампаний нужны;
- какие группы должны быть внутри.

2. Разделяй:
- Поиск;
- РСЯ;
- Ретаргетинг;
- брендовые запросы;
- околоцелевые запросы;
- теплую аудиторию.

3. Для каждой кампании укажи:

- цель;
- интент;
- тип трафика;
- сегмент аудитории;
- структуру групп;
- логику разделения.

---

# ПРАВИЛА

- 1 группа = 1 интент;
- не смешивай холодный и теплый трафик;
- не смешивай поиск и РСЯ;
- не создавай мусорные группы;
- структура должна быть пригодна для масштабирования.
- разделяй горячий / теплый / холодный спрос;
- отдельно выделяй high intent запросы;
- отдельно выделяй информационные запросы;
- отдельно выделяй эмоциональные запросы;
- отдельно выделяй брендовые запросы;
- отдельно выделяй околоцелевые запросы;
- отдельно выделяй ретаргетинг;
- не объединяй разные мотивы в одну кампанию;
- учитывай стоимость клика и вероятность конверсии;
- для дорогих направлений создавай отдельные кампании;
- для РСЯ используй эмоциональные триггеры;
- для Поиска используй точный интент;
- думай как performance-маркетолог, а не как копирайтер.

# КЛАССИФИКАЦИЯ ИНТЕНТОВ

## High Intent
Человек хочет записаться или купить сейчас.

Примеры:
- записаться
- цена
- стоимость
- рядом
- пробное занятие

---

## Research Intent
Человек изучает варианты.

Примеры:
- что такое
- польза
- отзывы
- для начинающих

---

## Emotional Intent
Человек ищет решение эмоциональной проблемы.

Примеры:
- снять стресс
- расслабление
- женская энергия
- раскрытие себя
- уверенность
