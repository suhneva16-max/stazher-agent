# ЧТО НУЖНО СДЕЛАТЬ

Для каждого запроса:

- оцени реалистичность;
- оцени поисковый интент;
- проверь естественность;
- проверь коммерческий смысл;
- найди мусорные запросы.

---

# ПРАВИЛА

Хороший запрос:
- реально ищут;
- короткий или средний;
- понятный;
- соответствует интенту;
- подходит для Яндекс Директ.

Плохой запрос:
- слишком длинный;
- звучит как текст нейросети;
- нереалистичный;
- без поискового спроса;
- мусорный.
