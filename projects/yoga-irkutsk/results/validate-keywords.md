## Йога и телесные практики

### Хорошие запросы
- пробное занятие йогой иркутск  
  Почему нормальный: краткий, сфокусирован на пробном занятии, включает регион, релевантен для записи.  
- йога для начинающих иркутск  
  Почему нормальный: конкретная аудитория (начинающие), регион, понятен и востребован.  
- занятия йогой для снятия стресса иркутск  
  Почему нормальный: отражает поисковый интент (решение проблемы стресса), добавлен регион.  
- телесные практики иркутск запись  
  Почему нормальный: ищут запись, чётко выражен коммерческий интент.  
- занятия телесными практиками для снятия стресса  
  Почему нормальный: направлен на запрос решения боли – снятие стресса.  
- где заняться телесными практиками в иркутске  
  Почему нормальный: пользователи обычно ищут места, запрос естественный.  
- телесные практики расписание иркутск  
  Почему нормальный: конкретный запрос, цель – узнать расписание, что важно для записи.

### Плохие запросы  
- йога расписание пробное иркутск  
  Почему плохой: немного некорректно построен, перебор слов, задумка ясна, но звучит неестественно.  
  Как исправить: йога пробное занятие расписание иркутск  
- занятия йогой для снятия стресса в иркутске бесплатно  
  Почему плохой: содержит минус-фразу "бесплатно", что не подходит под коммерческий смысл.  
  Как исправить: убрать слова "бесплатно"

## Танцы для женщин

### Хорошие запросы  
- танцы для женщин иркутск  
  Почему нормальный: простой, понятный, отражает целевую аудиторию, регион учитывается.  
- женские танцевальные курсы иркутск  
  Почему нормальный: более формальный запрос для выбора курсов, коммерчески привлекательный.  
- танцы для начинающих женщин иркутск  
  Почему нормальный: конкретная аудитория, лонгтейл, естественный.  
- женские танцы пробное занятие иркутск  
  Почему нормальный: явно выражен коммерческий интент – записаться на пробное занятие.

### Плохие запросы  
- танцы для женщин иркутск отзывы  
  Почему плохой: содержит минус-фразу "отзывы" – обычно не подходит для рекламы, пользователи ищут свободный контент.  
  Как исправить: убрать "отзывы", можно сделать отдельную рекламу для работы с отзывами.  
- женские танцевальные курсы иркутск бесплатно  
  Почему плохой: содержит "бесплатно", противоречит коммерческим целям.  
  Как исправить: убрать "бесплатно"

## Парные танцы (танго, бачата, хастл)

### Хорошие запросы  
- танго иркутск  
  Почему нормальный: короткий, охватывает пользователей, интересующихся танго.  
- уроки танго для пар иркутск  
  Почему нормальный: четко выделена аудитория — пары, комерческий интент.  
- танго для начинающих иркутск  
  Почему нормальный: понятно, что ищут занятия для новичков.  
- пробное занятие танго иркутск  
  Почему нормальный: запрос с выраженным интентом на запись.  
- бачата для пар иркутск  
  Почему нормальный: короткий и понятный запрос.  
- обучение бачате иркутск  
  Почему нормальный: коммерческий запрос.  
- парные танцы бачата уроки  
  Почему нормальный: естественный и релевантный.  
- бачата пробное занятие иркутск  
  Почему нормальный: четко выраженный коммерческий интент.  
- хастл обучение иркутск  
  Почему нормальный: конкретный запрос с коммерческим намерением.  
- хастл танцы курсы иркутск  
  Почему нормальный: коммерческий запрос, подразумевает запись на курсы.  
- пробное занятие хастл иркутск  
  Почему нормальный: четко выражено желание записаться на пробу.  
- уроки хастл для начинающих  
  Почему нормальный: направлено на новичков, понятный запрос.

### Плохие запросы  
- танго сальса иркутск  
  Почему плохой: смешивает два разных танца (танго и сальса), очень разный интент, плохо для группировки.  
  Как исправить: разбить на два запроса или использовать отдельные кампании.  
- обучение бачате иркутск бесплатно  
  Почему плохой: содержит "бесплатно", что не подходит для прямой рекламы платных курсов.  
  Как исправить: убрать "бесплатно".

## Мусорные запросы (минус-фразы, нецелевые)

- бесплатно  
- скачать  
- фото  
- своими руками  
- отзывы  
- форум  
- работа  
- вакансии

Эти запросы не подходят для рекламных кампаний, так как не являются коммерческими и ведут к мусору.

# Вывод

Для эффективной рекламной стратегии лучше использовать качественные запросы, четко распределённые по группам в соответствии с интентом. Исключать любые, содержащие слова из списка минус-фраз, либо нерелевантные и слишком длинные, неестественные запросы. Это повысит CTR, снизит бюджет на неэффективные показы и улучшит конверсию записей на пробные занятия.
