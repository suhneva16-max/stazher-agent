# Анализ целевой аудитории — Twin Cities Melbourne (Хостел, СПб)

---

## Сегменты аудитории

### 1. Путешественники-одиночки (18–35 лет)
**Факт:** Основная аудитория хостелов по всему миру.
- Студенты, фрилансеры, цифровые кочевники
- Приезжают на 1–5 дней
- Ищут дешевле, чем отель, но с атмосферой

### 2. Пары и молодые семьи с детьми
**Факт:** Продукт «семейные номера с санузлом» прямо указывает на этот сегмент.
- Хотят приватность, но не готовы платить за отель
- Приезжают на выходные или праздники

### 3. Туристы из регионов России
**Факт:** Хостел рядом с Московским вокзалом — естественный трафик приезжих.
- Прилетают/приезжают впервые в СПб
- Важна транспортная доступность

### 4. Любители нишевого туризма / «тематических» мест
**Гипотеза:** Живые поссумы + австралийский интерьер — редкий триггер.
- Люди, которые ищут опыт, а не просто ночёвку
- Делятся в соцсетях, высокий вирусный потенциал

## Боли

| Боль | Сегмент |
|------|---------|
| Шумные соседи в дормитории | Все |
| Неудобное расположение — далеко ехать до центра | Туристы из регионов |
| Страх грязи и антисанитарии в хостеле | Семьи, пары |
| Нет приватности | Пары, семьи |
| Непонятно, что за место — скучная коробка | Нишевые туристы |
| Нельзя забронировать онлайн быстро и уверенно | Все |

---

## Страхи

- «Хостел = шум, нет сна» → закрывает **звукоизоляция**
- «Придётся идти через весь двор ночью» → закрывает **отдельный вход с улицы**
- «Дёшево — значит плохо» → закрывает **тематический интерьер + поссумы** (необычное = запоминающееся = доверие)
- «Забронирую — потом проблемы» → закрывает **онлайн-бронирование со скидкой** (прозрачность)

| Отдельный вход | Безопасность, независимость |

## Мотивация

- **Рациональная:** сэкономить vs отель, жить в центре, приехать и сразу заселиться
- **Эмоциональная:** получить опыт, рассказать друзьям, сделать фото с поссумом
- **Социальная:** «я живу не в скучном отеле, а в классном месте»

## Выводы для рекламы

**Главные рабочие связки:**
- Поссумы + эмоция → РСЯ, нишевая аудитория
- Московский вокзал + удобство → Поиск, транспортный интент
- Семейный номер + приватность → отдельная группа на поиске
- Звукоизоляция + хостел → отработка страха, поиск

**Что НЕ стоит педалировать в рекламе:**
- Цену (нет подтверждённых данных для сравнения)
- «Лучший хостел» (запрещено по правилам)
- Обещания уровня сервиса без подтверждения
