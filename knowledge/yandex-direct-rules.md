# Правила Яндекс Директ

## Ограничения заголовков

- Заголовок 1: до 56 символов
- Дополнительный заголовок: до 30 символов

## Ограничения текста

- Текст объявления: до 81 символа

## Важные правила

- Не использовать кликбейт
- Не обещать гарантированный результат
- Избегать CAPS LOCK
- Использовать конкретику
- Добавлять преимущества
- Учитывать интент запроса

## Для РСЯ

- Использовать эмоциональные триггеры
- Делать акцент на проблеме
- Показывать выгоду
- Использовать читаемые тексты

## Для Поиска

- Максимально релевантный запросу заголовок
- Конкретные УТП
- Высокая точность интента
